# Assets for wallet-visual-snapshot.html

The snapshot embeds its two small fonts and the built styles. The Eupova logo is a 1 MB image, so the page refers to it
by a relative file instead. To show the logo, put the original here as `eupova-mark.png`
(it is `src/assets` / the built `assets/eupova-mark-*.png`). Without it the page works and just shows no logo.
