Connected tools

A connected tool, such as a command-line client, can ask your wallet to pay. It needs two things from you every time: an allowance you chose, and your approval of each payment. It can never approve for itself.

How a tool connects
  1. In a terminal: node scripts/eupova-tool-cli.mjs enrol --url YOUR_PREVIEW_URL --name "My CLI"
  2. Enter the code it prints above.
  3. Run enrol-wait, then give the tool an allowance here.
  4. The tool runs pay. The request appears under Pending approvals.

Test settings: wallet providers

The same wallet screen can sit on different providers. Only the simulated one is switched on here. The others stay closed until their setup is reviewed and approved.

  • Simulated wallet

    In use

    Fake address, test money. Used for the offline preview. Not a real wallet.

  • Circle user-controlled wallet

    Closed

    The customer sets a PIN and recovery questions in a Circle-hosted step and approves each payment with it. Code is written against the installed SDK; it is closed until the items below are provided.

    Needed before it can open
    • A Circle Standard Developer API key with User-Controlled Wallets access. Created by the account owner in the Circle Console. EUPOVA_CIRCLE_UCW_API_KEY
    • The User-Controlled Wallets application id from the Console (used only by the browser SDK). EUPOVA_CIRCLE_UCW_APP_ID
    • A random secret of at least 32 characters that Eupova uses to derive each customer's opaque Circle user id. Generated by the operator and kept out of source control. EUPOVA_CIRCLE_UCW_USER_ID_SECRET
    • The literal value "test". Anything else keeps this provider closed. Mainnet is not supported by this build. EUPOVA_CIRCLE_UCW_MODE
    • An explicit go-ahead from the account owner after reviewing credentials, Circle terms and permissions, and app configuration.

  • Privy embedded wallet (existing work, comparison only)

    Closed

    The earlier Privy wallet-setup work is kept unchanged for comparison. It is not connected to this screen and no Privy wallet is created.

    Needed before it can open
    • The existing Privy setup, durable guard and wallet-creation approval described in docs/privy-wallet-setup-adapter.md.
